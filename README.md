# Buklet Kemiskinan dan Pertumbuhan Ekonomi Kabupaten Kulon Progo 2024

## Deskripsi Proyek

Proyek ini merupakan pembuatan buklet publikasi mengenai kondisi kemiskinan dan pertumbuhan ekonomi di Kabupaten Kulon Progo tahun 2024.

Buklet disusun sebagai media penyajian informasi statistik dalam bentuk visual yang informatif dan mudah dipahami. Proyek ini dikerjakan selama kegiatan Praktik Kerja Lapangan (PKL) di Badan Pusat Statistik Kabupaten Kulon Progo.

## Tools

- Microsoft Excel
- Canva

## Project Overview

Buklet ini menyajikan informasi statistik terkait kemiskinan dan pertumbuhan ekonomi Kabupaten Kulon Progo tahun 2024.

Informasi disusun dalam bentuk ringkasan dan visualisasi untuk membantu pembaca memahami kondisi sosial ekonomi daerah.

## My Contribution

Dalam proyek ini, kontribusi yang dilakukan meliputi:

- Mengolah dan menyiapkan informasi statistik yang akan disajikan.
- Menyusun informasi mengenai kemiskinan dan pertumbuhan ekonomi.
- Membuat desain dan tata letak buklet menggunakan Canva.
- Menyajikan informasi statistik dalam bentuk publikasi visual yang informatif.
